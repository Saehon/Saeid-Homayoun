# Replication Registry

Priority benchmark papers and packages will be documented here before adapting methods.

For each benchmark record:
- citation and DOI
- journal / ranking
- research question
- data accessibility
- code repository
- license/reuse restrictions
- reproduction status
- methods reused in AICapEx-Value
- deviations from the published design

Replication code is a methodological benchmark; proprietary source data must not be redistributed.
