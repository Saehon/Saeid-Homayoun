## Release and linkage policy
A Drive document is always canonical. Every GitHub data manifest has DOI/URL, effective licence, provenance, access date, caveat, source hash and dataset key. Publish only legally redistributable cleaned/aggregated data, keep third-party originals external, and require human sign-off. No automatic synchronization with HF or Kaggle is currently configured; public URLs are cross-references, not a live machine-to-machine connection. Do not store personal data or API keys in GitHub.
