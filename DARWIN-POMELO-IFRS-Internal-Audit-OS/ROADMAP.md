| Week | Build | Exit criterion |
|---|---|---|
| 1 | Freeze architecture, schemas and project structure | Architecture v1.0 approved |
| 2 | Antigravity control-plane adapter + POMELO router skeleton | One routed end-to-end demo |
| 3 | Knowledge Core MVP: IFRS 15/16 | Versioned rule objects + tests |

## Immediate priorities

1. Implement the POMELO task/materiality/cost router before adding more agents.
2. Add Antigravity, OpenAI, Anthropic, IBM and local provider adapters to the private runtime.
3. Build IFRS 15 as the first complete vertical slice.
4. Use deterministic and local/open tools first.
5. Freeze benchmark cases before comparative model claims.
6. Keep patent-sensitive routing/evaluator details private pending IP review.
