# ECONOVA-S™ External Method Provenance

This file records the public source basis for external scientific-AI systems referenced by ECONOVA-S™.

These references establish **methodological provenance only**. They do not imply sponsorship, affiliation, partnership, access rights, or that ECONOVA-S™ executed the external systems.

## Google DeepMind — AlphaFold

Official source:
https://deepmind.google/science/alphafold/

AlphaFold is a biological structure-prediction system. ECONOVA-S™ does not claim that AlphaFold itself is an economics model.

The project borrows only the higher-level scientific idea that important problems may require inference over hidden structure plus rigorous external benchmarking.

ECONOVA-S™ mapping examples:

- hidden regimes;
- network/community structure;
- latent risk dimensions;
- hidden mechanism classes;
- hierarchical constructs.

## Independence rule

All external system names are used for methodological attribution or architectural inspiration unless an actual execution is separately documented with:
- access method;
- model/system version;
- execution date;
- inputs;
- outputs;
- provenance;
- Evidence Passport™ entry.

No such name by itself establishes endorsement or affiliation.
