# Hugging Face Model Registry

Use this folder to record the exact Hugging Face models used in reproducible accounting and auditing experiments.

IBM models should be registered with:
- model ID
- revision/commit
- license
- task
- domain
- dataset
- evaluation metrics
- date accessed

Recommended IBM starting points:
- IBM Granite language models
- IBM Granite Embedding models
- IBM Granite time-series models where appropriate

Hub: https://huggingface.co/ibm-granite
