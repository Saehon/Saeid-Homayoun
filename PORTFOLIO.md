# Saeid Homayoun — Research & AI Portfolio

## Positioning

I work at the intersection of **accounting, auditing, finance, economics, sustainability, data science, and agentic AI**. My portfolio is organized around one principle:

> **AI should not merely generate research text; it should help create, test, challenge, reproduce, and audit scientific evidence.**

The flagship platform is **ECONOVA-S™ Research Co-Scientist**, supported by domain-specific research systems for audit, financial text, time-series risk, and sustainability.

## 1. ECONOVA-S™ Research Co-Scientist

### Research problem

Can a governed multi-agent system move from a research question to a reproducible empirical study while preserving theory, identification, provenance, falsification, replication, and human scientific control?

### Agentic architecture

**Literature Agent → Co-Scientist Hypothesis Arena → Theory/DAG Agent → ERA Empirical Compiler → Data/Construct Agent → Econometric/ML Agent → ResearchEvolve → Replicator → Critic → Defender → Judge → Evidence Auditor → Human Gate**

### Scientific inspirations

- AI Co-Scientist-style hypothesis generation, critique, ranking, and evolution;
- ERA-style conversion of hypotheses into executable empirical programs;
- AlphaEvolve-inspired search over measures, models, estimators, algorithms, and specifications;
- Computational Discovery-style candidate generation and evaluation;
- AlphaFold-inspired search for latent economic structures with interpretation and external validation;
- Science One-inspired Chain-of-Evidence;
- Mirendil-inspired closed-loop R&D orchestration;
- AI-to-AI independent review and explicit DAG governance.

### Initial public-data benchmark

- Kenneth R. French Data Library;
- Aswath Damodaran / NYU Stern industry data;
- SEC EDGAR / XBRL CompanyFacts.

### Outputs

- ranked competing hypotheses;
- empirical research objects;
- executable Python/R/Stata designs;
- publication-style tables;
- robustness and falsification reports;
- independent replication report;
- Chain-of-Evidence;
- Evidence Passport™;
- explicit Human Gate decision.

# Universal Scientific Discovery Contract

Every serious study should follow:

```text
Question
→ FT50/AJG literature validation
→ competing hypothesis generation
→ critique / defend / rank
→ theory + DAG governance
→ ERA empirical conversion
→ authoritative data + provenance
→ executable code
→ model / construct / specification evolution
→ temporal or external validation
→ adversarial AI-to-AI review
→ falsification
→ independent replication
→ Chain-of-Evidence
→ Evidence Passport
→ Human Gate
```

## Non-negotiable rules

```text
optimize_for_p_value = false
agent_consensus_is_scientific_truth = false
failed_results_are_deleted = false
human_gate_required = true
discovery_claim_allowed = false  # until all gates pass
```
