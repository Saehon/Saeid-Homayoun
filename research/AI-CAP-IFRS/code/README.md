# Code and replication — AI-CAP-IFRS

This is a scaffold, **not** a claim that firm-panel regressions or return tests have run.

## Proposed sequence
1. Freeze firm/year roster and link to publication dates and audit-report dates.
2. Extract cash flow, capex, earnings, impairment and intangible facts from IFRS reports.
3. Validate monetary attribution to AI projects using direct source evidence and dual human review.
4. Calculate annual contemporaneous disclosure-based financial metrics with reconciliation checks.
5. Run pre-registered announcement-window pricing analyses against matched benchmarks and factor models.
6. Produce audit trail: input hashes, transformations, control models, robustness tests, provenance and limitations.

Use reproducible Python (pandas, statsmodels) or R, and clearly label any illustrative/synthetic test fixtures.

Prior academic code references include [Babina et al. (2024) JFE](https://doi.org/10.17632/s26kxvspn7.3); this reference **does not** mean those authors' analyses have been rerun here.
