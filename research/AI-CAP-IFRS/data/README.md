# Data — AI-CAP-IFRS

**Google Drive is authoritative.** This GitHub folder contains descriptions, collection scripts and licenses, not redistributed financial reports.

| Data | Source | Restriction/verification |
|---|---|---|
| IAS 7 cash flows; IAS 16 capex; IAS 36 impairments; IAS 38 intangible disclosures | [filings.xbrl.org](https://filings.xbrl.org/) and official issuer reports | Confirm issuer, fiscal year, currency, units, CGU boundaries and filing date |
| AI-specific monetary investment | Verified source passages from audited notes, issuer disclosures | Do not substitute generic total PPE purchases or AI-keyword counts |
| KAM narratives | Auditor's report from published IFRS filing | Verify text source and identical-day availability |
| Equity returns | Lawfully reusable exchange/provider series | Preserve split/dividend adjustments, currency, timestamp and license |
| Factor benchmarks | [Kenneth French](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html) | Match market geography and reporting/trading days |
| Industry cost of capital | [Damodaran](https://pages.stern.nyu.edu/~adamodar/) | Match industry vintage and geography |

No user private data, full unlicensed datasets, API tokens or proprietary manuscripts are committed here. Dataset metadata and exact origin/licensing must be reviewed before Kaggle/Hugging Face publication.
