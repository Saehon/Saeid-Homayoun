# Kaggle public-distribution package

This folder is prepared for a **public Kaggle dataset containing synthetic material only**.

## Intended Kaggle slug
`sadhon/darwin-jev-risk-cam-synthetic-replication`

## Publishable content
- `data/SYNTHETIC_demo.csv`
- public README / data dictionary
- schema validator and unit tests
- `dataset-metadata.json`

## Excluded
The unpublished JAR manuscript, private Google Drive datasets, real CAM/ICFR outcome labels, restricted third-party data, tokens, credentials, and proprietary weights must NOT be uploaded.

The public dataset is a reproducibility starter; it is not evidence for the study's hypotheses.
