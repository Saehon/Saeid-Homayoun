## Scientific discovery protocol

> **Models generate. Agents debate. Code tests. Evidence decides. Humans approve.**

Research Question → Literature Validation → Competing Hypotheses → Multi-Agent Critique → ERA-style Empirical Design → Computational Discovery / AlphaEvolve-inspired search → latent-structure reasoning → Empirical Test → Adversarial Review → Falsification → Temporal/Out-of-Sample Validation → Replication → Chain-of-Evidence → DAG Governance → Human Gate.

No LLM/model output or statistically significant result is automatically treated as scientific discovery.

## First empirical study enabled by the executable platform

Primary research question:

**Does governed multi-agent audit orchestration improve evidence grounding and professional judgment relative to single-agent AI?**

Intended comparison:

1. deterministic control;
2. single-agent AI;
3. sequential-agent AI;
4. governed multi-agent AI;
5. human-only / human-led baseline where feasible.

Primary outcomes: RPA, AA, EG, PS, DS, DIST, exception detection, false positives/negatives, decision stability, completion time, cost, reproducibility and human overrides.

Prototype 004 should execute real provider/model adapters against frozen evidence before any comparative AI result is reported.
