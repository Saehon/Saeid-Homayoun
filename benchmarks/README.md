# Benchmarks

Shared benchmarks for accounting and auditing AI.

Minimum benchmark dimensions:
- extraction accuracy
- classification precision / recall / F1
- false-positive and false-negative rates
- evidence-grounding / citation validity
- reproducibility
- temporal integrity
- reviewer disagreement
- falsification survival
- human approval rate

Compare IBM Granite configurations against other open baselines only under the same dataset split, prompt policy and evaluation protocol.
