# Kimi + DeepSeek Open Stack for Accounting, Finance & Auditing

This Hugging Face dataset is a **registry and reproducibility package**, mirrored from the canonical GitHub source:

https://github.com/Saehon/Saeid-Homayoun/tree/main/ai-stacks/kimi-deepseek-accounting-finance-audit

It catalogs open/free models, repositories, datasets, SEC/XBRL tooling, and setup scripts for research and education in accounting, auditing, assurance, finance, fraud, financial reporting, and financial AI.

## Important distribution rule

This mirror does **not** re-host third-party model weights or third-party datasets. Each upstream asset retains its own license and provenance. The catalog provides canonical upstream links and optional download tooling.

## Core practical baselines

- DeepSeek-R1-Distill-Qwen-7B
- Kimi-VL-A3B-Instruct
- FinQA
- FinanceBench
- FinGPT
- FinBERT
- FinRL
- Arelle
- EdgarTools
- SEC EDGAR / XBRL

## Files

- `catalog.csv` — machine-readable registry.
- `README_GITHUB.md` — full canonical documentation snapshot.
- `requirements.txt` — Python dependencies.
- `download_assets.py` — upstream downloader.
- `setup.ps1` / `setup.sh` — local setup.
- `INTEGRATION_MANIFEST.json` — cross-platform provenance.

## Canonical source

GitHub remains the source of truth. Hugging Face and Kaggle are public mirrors for discovery, reproducibility, and teaching.
