# Accounting, Finance & Audit Open Data and Program Registry

Cross-platform public registry maintained from the canonical GitHub repository of Saeid Homayoun.

It connects free/public resources across **GitHub, Hugging Face and Kaggle** for accounting, auditing, assurance, finance, fraud/AML, SEC/EDGAR/XBRL, ESG/sustainability, Microsoft/Copilot and IBM/watsonx research.

## What this mirror contains

- `program_catalog.csv` — curated public/free program catalogue.
- `data_catalog.csv` — curated public/free dataset catalogue.
- `combined_catalog.csv` — unified programme + data view.
- `repos.yml` — canonical GitHub programme registry.
- `data_sources.yml` — canonical cross-platform data registry.
- `REGISTRY_MANIFEST.json` — counts, targets and publication policy.
- `SHA256SUMS.json` — integrity hashes.

## Important licensing rule

This mirror contains **metadata, links, registry records and original curation only**. It does not re-publish third-party source code or large third-party datasets. Each linked upstream repository or dataset retains its own licence and terms.

A resource being public/free to download does not mean its associated cloud runtime is free. Microsoft/Azure/Copilot and IBM/watsonx examples may require separate accounts, credentials or paid services.
