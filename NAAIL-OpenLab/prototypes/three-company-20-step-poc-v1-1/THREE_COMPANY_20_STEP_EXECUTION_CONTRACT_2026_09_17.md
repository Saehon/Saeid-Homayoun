# NAAIL OpenLab™ — Three-Company 20-Step POC / Prototype V1.1 Execution Contract

**Date:** 2026-09-17  
**Maturity:** `RESEARCH_PROTOTYPE`  
**Architecture:** exactly two permanent cores — Stable Knowledge Core™ + Replaceable Technology Core™  
**Companies:** Microsoft (`MSFT`), Walmart (`WMT`), JPMorgan Chase (`JPM`)  
**Contract size:** **3 companies × 20 steps = 60 company-step executions**

> **PATENT RIGHTS RESERVED — PATENT APPLICATION PREPARATION IN PROGRESS**

## Purpose

This contract converts the NAAIL roadmap into a bounded proof-of-concept and prototype validation program. Microsoft remains the Golden Anchor. Walmart and JPMorgan are the first replication companies because they stress materially different accounting, audit, operating and risk environments.

No step is promoted merely because data are accessible, code exists, or an architecture diagram exists. Every step must end in an explicit execution status and preserve provenance, limitations, contradictory evidence and unresolved gates.

## Companies

### Company 1 — Microsoft Corporation (`MSFT`)
Technology / cloud / AI. Canonical Golden Anchor and reference implementation.

### Company 2 — Walmart Inc. (`WMT`)
Retail / operations / supply chain. Required sector adapter: inventory, gross margin, leases, working capital, supply-chain controls and retail operating metrics.

### Company 3 — JPMorgan Chase & Co. (`JPM`)
Banking / financial instruments. Required sector adapter: loans, credit losses, capital/liquidity, financial instruments, interest income and bank-specific balance-sheet measures. Ordinary industrial-company ratios must not be applied mechanically.

## Status vocabulary

The public package uses only these controlled execution labels where applicable:

`EXECUTED_VALIDATED` · `RESEARCH_PROTOTYPE` · `EXECUTED` · `DERIVED_EXECUTED` · `SYNTHETIC_EXECUTED` · `DESIGN_ONLY` · `REGISTERED_NOT_EXECUTED` · `PATENT_HOLD_NON_ENABLING`

A separate source-access field may state that public/free evidence is verified; source availability does not change an execution status.

## Current starting boundary

Microsoft already contains substantial executed evidence and the bounded 15/15 artifact-validation harness, but several scientific gates remain open. Walmart and JPMorgan have public/free source paths and verified market access, but their 20-step pipelines remain `REGISTERED_NOT_EXECUTED` until reproducible runs are completed.

The canonical machine-readable starting state is `three_company_60_step_execution_matrix.csv`.

## Promotion rule

A company may move from POC to replicated prototype only when the common 20-step contract is materially completed, unresolved failures are explicit, and Human Gate + independent replication requirements are satisfied for the claims being promoted.

**Data accessible ≠ analysis executed. Code written ≠ result executed. Agent agreement ≠ verified evidence. Statistical significance ≠ scientific discovery.**
