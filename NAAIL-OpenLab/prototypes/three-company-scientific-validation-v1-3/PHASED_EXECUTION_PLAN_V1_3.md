## Purpose

Prototype V1.3 is deliberately divided into four scientific phases. Each phase must be validated and published independently before the next phase can be promoted. A failed, contradictory, blocked or non-reproduced result is preserved rather than silently removed.

## Phase 1 — Reproducibility & Factor Falsification

Resolve the V1.2 replay discrepancy; rerun factor-model robustness; compare HC3 with HAC(3); evaluate influence diagnostics and leave-one-month-out stability; preserve split/dividend/window sensitivity; and freeze a clean replay package.

Allowed outcomes include `SUPPORTED_AFTER_CHALLENGE`, `REVISED_AFTER_CHALLENGE`, `REQUEST_MORE_EVIDENCE`, `REJECTED_BY_FALSIFICATION`, `BLOCKED`, and `NOT_EXECUTED`.

## Phase 2 — Blind Professional AI Benchmark & Cost

Use fresh holdout accounting/audit tasks with gold answers separated from public execution prompts. Independently invoke multiple models when available; score CAM classification, assertion mapping, ICFR reasoning, accounting judgment, evidence retrieval, contradiction detection and explanation quality; capture latency and cost telemetry; then calculate Cost per Verified Professional Output™ only from real observed telemetry.

Until independent model calls occur, this phase remains `RESEARCH_PROTOTYPE` / `REGISTERED_NOT_EXECUTED` as appropriate.

## Phase 3 — Innovation + Human–AI Scientific Readiness

Complete patent entity resolution and aggregate patent/citation/technology-diversity measures where the USPTO data route permits reproducible access. In parallel, freeze power analysis, T0–T3 preregistration, instruments and Digital Twin integration. Participant outcomes remain `DESIGN_ONLY` until actual human observations exist.

## Phase 4 — Human Gate & Independent Replication

Run the professional Human Gate™ with `APPROVE / REVISE / REQUEST_MORE_EVIDENCE / REJECT / ESCALATE`, then execute a clean independent replay by another environment/reviewer. Prototype V1.3 can only be frozen after the preceding scientific gates are reviewed.

## Promotion rule

`V1.2 → V1.3 Phase 1 → Phase 2 → Phase 3 → Phase 4 → V1.3 Final`

No phase is promoted because data are accessible, code exists, agents agree, or a coefficient is statistically significant.
