## Scientific operating model

> **AI proposes. Co-Scientists compete. ERA operationalizes. AlphaEvolve improves. Computational Discovery searches. Latent-Structure Agents reveal. DAGs discipline causality. Code tests. AI reviewers challenge. Replication verifies. Evidence decides. Humans approve.**

## Core pipeline

```text
Research Problem
→ Literature Validation / Literature Insights-style Grounding
→ Co-Scientist Hypothesis Arena
→ DAG Governance
→ ERA Empirical Design
→ Rights-Cleared Real Data or Selected NAAIL Digital Twin
→ AlphaEvolve-style Search
→ Computational Discovery
→ AlphaFold-inspired Latent Structure
→ Domain-Specific Forecasting / Simulation when justified
→ Robustness / OOS Validation
→ AI-to-AI Adversarial Review
→ Falsification
→ Independent Replication
→ Science One-style Chain-of-Evidence + CoE Audit
→ Evidence Passport™
→ Human Gate™
```

## Provider-neutral execution

NAAIL is designed to benchmark and orchestrate multiple provider frameworks behind a common evidence and governance layer, including OpenAI Agents SDK, Claude Agent SDK, Google ADK / Gemini tooling, Microsoft Agent Framework, MCP, A2A, and eligible local/open-source models.

Google Research / DeepMind system names are **methodological references or optional provider targets by default**. They count as actually executed only when an Evidence Passport records the real system/model, version, inputs, outputs, access rights and run provenance.

## Non-negotiable rule

No model output, statistical significance, predictive accuracy, agent consensus, provider name or Digital Twin result is treated as scientific discovery without literature validation, reproducible empirical testing, adversarial review, falsification, replication, Chain-of-Evidence, and Human Gate approval.
