# NAAIL OpenLab™ — Public Release Checklist

Before any public release, confirm all items below.

## Research integrity
- [ ] Version and release date are explicit.
- [ ] Claims are labeled exploratory/predictive/causal/replicated as appropriate.
- [ ] No unsupported “scientific discovery” claim.
- [ ] Methods, data provenance, limitations, and evaluation criteria are documented.
- [ ] Negative/failed results are not selectively hidden when material.

## Evidence and rights
- [ ] No copyrighted standards/articles/course packs are redistributed without permission.
- [ ] Dataset redistribution rights are confirmed.
- [ ] AJG/ABS material is referenced lawfully rather than republished as a licensed database.
- [ ] Third-party trademarks/logos/screenshots are not used in a misleading way.
- [ ] Big Four references are descriptive/public-information benchmarking only.

## Privacy/security
- [ ] No secrets or credentials.
- [ ] No personal/student/client/confidential data.
- [ ] No private repository links/tokens.
- [ ] Synthetic cases are clearly labeled.
- [ ] Generated artifacts have been checked for accidental sensitive disclosure.

## IP/patent
- [ ] Public/private classification completed.
- [ ] Patent-sensitive enabling details remain private unless cleared.
- [ ] “Patent pending” is not used unless an application has actually been filed.
- [ ] Contributor/IP status is clear.

## Software quality
- [ ] Frozen evals pass.
- [ ] No critical regression.
- [ ] Known limitations are documented.
- [ ] Citation metadata matches the released version.
- [ ] License and commercial-use restrictions are present.
- [ ] Rollback/previous release reference is preserved.

## Human approval
- [ ] Final public release approved by the project owner/research lead.
