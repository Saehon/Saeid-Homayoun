# NAAIL OpenLab™ — Public Patent Filing Checklist

> **PATENT RIGHTS RESERVED — PATENT APPLICATION PREPARATION IN PROGRESS**

This is a public administrative checklist only. Detailed enabling patent drafts, claim concepts, technical diagrams, and confidential patentability analysis are maintained privately.

## Before filing

- [x] Adopt patent-first disclosure policy.
- [x] Establish private patent-readiness workspace.
- [x] Record known public GitHub disclosure dates/commits.
- [x] Add public patent/IP notices without using “Patent Pending.”
- [ ] Complete professional inventorship review.
- [ ] Review employment, university, grant, collaboration, contributor, and assignment obligations.
- [ ] Complete professional prior-art/patentability search.
- [ ] Review patent-eligible/technical-character issues in intended jurisdictions.
- [ ] Review public-disclosure consequences for intended jurisdictions.
- [ ] Finalize complete enabling specification privately.
- [ ] Finalize necessary patent drawings privately.
- [ ] Confirm inventor residence/correspondence information required by the selected filing route.
- [ ] Confirm filing fees and forms immediately before filing.
- [ ] File through the applicable patent office/authorized channel.
- [ ] Obtain and archive the official filing receipt.

## After confirmed filing

Only after an actual filing is independently confirmed:

- [ ] change public status to **PATENT PENDING** where appropriate;
- [ ] record patent office;
- [ ] record application number;
- [ ] record filing date;
- [ ] record priority date;
- [ ] record inventor(s) exactly as filed;
- [ ] preserve a hash/copy of the filed specification and drawings;
- [ ] decide which previously confidential technical materials may then be disclosed;
- [ ] keep later unfiled improvements confidential until reviewed.
