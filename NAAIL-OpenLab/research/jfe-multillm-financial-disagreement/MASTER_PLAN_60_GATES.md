DARWIN: Define → Alternatives → Retrieve/Replicate → Whole-system dependencies → Invalidate/Falsify → Next evolution.
Co-Scientist: hypothesis generation, critic, falsifier, novelty check, ranking, meta-review.

Science Discovery: maintain a graph connecting theory, literature, evidence, hypotheses, anomalies, tests and discoveries.
100-CEO Scientific Board: 10 councils × 10 perspectives used as structured adversarial review roles, not fabricated independent agents.
Human Gate: scientific/governance approval remains human-controlled.

## Status vocabulary
NOT_STARTED → ACTIVE → PARTIAL → PASS
or BLOCKED → REPAIR_QUEUE → CLOSED.
CLOSED is not PASS.

## Two-fail move-on rule
After two failed hourly runs on the same task/blocker: preserve both failure records and exact repair action; classify blocker; quarantine dependency-critical outputs; move immediately to the next scientifically admissible executable gate. Never fabricate PASS and never bypass a dependency that invalidates downstream inference.

## Hourly run protocol
0–2 min: reconstruct GitHub/Drive/run-ledger/repair-queue state.
2–11 min: highest-priority unfinished admissible gate.
11–13 min: test/falsify/readback.
13–15 min: dual-save GitHub + Google Drive, verify, log, assign next gate.
Every run records phase/gate, evidence, files, commit, tests, Drive readback, fail count, repair queue and next gate.
