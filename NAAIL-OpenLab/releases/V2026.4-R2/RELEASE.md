## Archival boundary

The current GitHub repository is an umbrella repository containing multiple research systems. Its root `CITATION.cff` is not NAAIL-specific.

Therefore, a NAAIL DOI should be minted using either:

1. a dedicated NAAIL repository with NAAIL metadata at repository root; or
2. a separate NAAIL-scoped Zenodo software deposit using the release-specific metadata included here.

Do not mint a NAAIL-specific DOI from mismatched root metadata.
