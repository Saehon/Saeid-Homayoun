# Zenodo Publication Request — NAAIL OpenLab™ V2026.4-R3

This file intentionally triggers the GitHub Actions workflow that publishes the frozen
`NAAIL-OpenLab-V2026.4-R3-Zenodo.zip` asset to Zenodo.

The workflow must stop safely when the repository secret `ZENODO_TOKEN` is absent.

The Zenodo token must have:
- `deposit:write`
- `deposit:actions`

No token value belongs in this repository or in this file.
