# NAAIL OpenLab™ Marketplace Support

## Current status

NAAIL OpenLab Marketplace Edition is a research-stage public scaffold and is not yet an approved public listing in the OpenAI, Google, or Microsoft marketplaces.

## Support model for production launch

Before any marketplace submission, NAAIL must provide a stable public support channel covering:

- account/access problems;
- product defects;
- security or privacy concerns;
- incorrect or unsafe tool behavior;
- data deletion/privacy requests;
- billing/entitlement issues for paid plans;
- reproducibility defects;
- evidence/provenance defects;
- provider/model outages.

## Severity targets

Production operations should classify incidents at minimum as:

- **Critical:** security breach, cross-tenant data exposure, credential leakage, or unsafe high-impact tool action;
- **High:** production outage, broken Human Gate, material evidence/provenance corruption;
- **Medium:** major feature failure without security impact;
- **Low:** documentation, UX, or non-blocking defects.

## Required pre-launch contact information

Before marketplace submission, this file and the production support site must include:

- legal/product entity name;
- support email or ticket URL;
- security/privacy reporting contact;
- normal support hours and timezone;
- escalation path for critical incidents;
- billing contact for commercial offers.

## Research issue reporting

For public research-safe documentation and reproducibility issues, GitHub Issues may be used where appropriate, provided that users are warned never to post credentials, confidential datasets, personal data, or restricted materials in public issues.
