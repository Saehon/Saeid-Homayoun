# MVP — DARWIN Sustainable Value Transformation OS™

## MVP promise

Before a material business commitment, calculate the relevant value impact relative to the best feasible alternative, preserve evidence and route material cases to the Human Gate.

## First event gates

- Purchase Order
- Sales Order
- Project / Contract context

## First outputs

- Accounting / domain status
- True or relevant cost
- Value impact
- Opportunity cost
- Best alternative
- Recommendation
- Confidence / evidence gaps
- Human approval tier
- Expected outcome and later actual outcome
