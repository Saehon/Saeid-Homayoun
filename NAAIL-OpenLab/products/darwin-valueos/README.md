# DARWIN ValueOS™ — Economic Value Creation Engine

**Status:** Public, non-enabling product architecture / research prototype specification  
**Umbrella:** NAAIL OpenLab™  
**North Star:** **Maximum Incremental Economic Value**

## Purpose

ERP-connected management-accounting decision engine that converts purchases, sales, projects, products, customers and suppliers into pre-transaction economic-value decisions.

## Canonical flow

`Cost Truth → Management Accounting → EVA/EVI → Opportunity Cost → Systems Thinking → Counterfactual → Decision → Learning`

## Primary inputs

PO, SO, invoice, inventory, production, project, supplier, customer, capacity and working capital

## POMELO-style governance backbone

Each engine reuses the POMELO-style discipline rather than a generic chatbot pattern:

- Evidence Passport / provenance
- Construct Firewall: fact ≠ estimate ≠ prediction ≠ causal claim ≠ recommendation ≠ approved action
- Competing hypotheses / Co-Scientist tournament
- Independent challenger and falsification
- Systems-thinking dependency graph
- Counterfactual worlds and best-alternative comparison
- Human Approval Gate for consequential actions
- Expected-versus-actual outcome attribution
- Failure memory and controlled learning

## Public / private boundary

This folder is deliberately non-enabling. Proprietary prompts, scoring logic, confidential datasets, production credentials, licensed IFRS text and patent-sensitive implementation remain private.
