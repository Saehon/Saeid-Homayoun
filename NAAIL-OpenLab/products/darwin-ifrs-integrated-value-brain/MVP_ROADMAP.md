# MVP Roadmap

## MVP goal

Prove one decision promise:

> **Before release of a purchase order or sales order, determine whether the transaction creates economic value relative to the best feasible alternative and route material cases to a human gate.**

## Phase 1 — Cost Truth

Inputs:

- purchase;
- inventory;
- production;
- sales;
- project;
- supplier;
- customer.

Outputs:

- true SKU / project cost;
- cost-to-serve;
- total cost of ownership;
- basic capital-use estimate.

## Phase 2 — Economic Objects

Build:

- Product Twin
- Project Twin
- Customer Twin
- Supplier Twin

Outputs:

- product / project profitability;
- working-capital use;
- capital charge;
- EVI / EVA.

## Phase 3 — Pre-transaction gates

Initial gates:

- Purchase Order
- Sales Order

Initial action set:

- APPROVE
- MODIFY
- REJECT

## Phase 4 — Counterfactuals

Add:

- supplier alternative;
- quantity / batch alternative;
- pricing alternative;
- delivery-time alternative;
- outsource / reschedule option.

## Phase 5 — Assurance & DARWIN

Add:

- evidence passport;
- construct firewall;
- challenger / falsification;
- human approval;
- CEO-100 reference classes;
- Co-Scientist hypotheses.

## Phase 6 — Sustainability and six capitals

Add only after the economic core is validated:

- double materiality;
- ISSB / ESG relevance;
- six-capital transmission;
- SVA;
- anti-double-counting controls.

## Phase 7 — Closed-loop learning

Compare:

```text
Expected Value → Approved Action → Actual Outcome → Attribution → Learning
```

## MVP success criteria

- reproducible decision calculations;
- no silent construct mixing;
- explicit opportunity cost;
- alternative ranking;
- auditable evidence trail;
- human override;
- expected-vs-actual outcome tracking.
