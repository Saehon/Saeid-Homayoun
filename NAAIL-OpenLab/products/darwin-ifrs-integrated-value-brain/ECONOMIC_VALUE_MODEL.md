# Economic Value Model

## 1. Cost Truth first

Economic value is not evaluated before the system determines decision-relevant cost.

Candidate costing methods:

- direct tracing;
- ABC;
- TDABC;
- standard costing;
- marginal / incremental costing;
- relevant costing;
- throughput accounting;
- target costing;
- lifecycle costing;
- customer cost-to-serve;
- total cost of ownership;
- avoidable cost.

The method is selected by the decision context rather than imposed globally.

## 2. True Economic Cost

A conceptual form is:

```text
True Economic Cost
= Direct Cost
+ Activity / Complexity Cost
+ Cost-to-Serve
+ Failure / Quality Cost
+ Working-Capital Cost
+ Capital Usage
+ Risk Cost
```

The implementation must include explicit anti-double-counting controls.

## 3. Economic Value Impact

For decision alternative `a`:

```text
EVI(a)
= Incremental Benefit(a)
- Relevant Cost(a)
- Capital Charge(a)
- Risk Cost(a)
- Opportunity Cost(a)
+ Strategic Option Value(a)
```

## 4. EVA

Where object-level capital allocation is meaningful:

```text
EVA(i) = NOPAT(i) - WACC × Invested Capital(i)
```

Supported economic objects may include:

- SKU
- product family
- project
- customer
- supplier
- contract
- plant
- business unit
- company

## 5. Opportunity cost

A positive accounting margin or positive EVA is not sufficient.

```text
Incremental Decision Value
= EV(Action) - EV(Best Feasible Alternative)
```

A value-creating project can still be an inferior allocation of scarce capital, capacity, labor, inventory or customer attention.
