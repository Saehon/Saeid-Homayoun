# IFRS Value Genome™

## Purpose

The IFRS Value Genome™ translates an IFRS-triggered accounting event into its economic and sustainability value pathways without pretending that every IFRS standard has a standalone EVA formula.

For each standard or standard family, the genome contains:

1. Trigger
2. Applicable accounting rule family
3. Recognition / measurement consequence
4. Economic object
5. True cost pathway
6. Relevant cost pathway
7. Capital-use pathway
8. Opportunity-cost pathway
9. Economic Value Impact (EVI)
10. Sustainability / materiality pathway when relevant
11. Six-capital transmission
12. Counterfactual alternatives
13. Assurance requirements
14. Decision gate
15. Actual-outcome learning

## Priority genome map

| Standard | Typical trigger | Value question |
|---|---|---|
| IFRS 15 | Sales order / contract | Does the customer contract create value after cost-to-serve, working capital and constrained capacity? |
| IFRS 16 | Lease | Lease vs buy vs outsource: which compliant alternative maximizes value? |
| IAS 2 | Inventory | Does this SKU create value after carrying cost, obsolescence and constrained capital? |
| IAS 16 | CapEx / PPE | Does the asset generate productivity and cash flows above capital charge and alternatives? |
| IAS 36 | Impairment signal | What operational or market mechanism is eroding value? |
| IAS 38 | R&D / software | Does expenditure create durable intellectual capability and future value? |
| IFRS 9 | Credit / financial instrument | What is risk-adjusted economic value after expected credit loss and funding effects? |
| IFRS 3 | Acquisition | Do synergies exceed acquisition premium, integration risk and opportunity cost? |
| IAS 37 | Provision / commitment | What is the probability-adjusted economic burden and best mitigation alternative? |
| IAS 19 | Employee benefits | What is the Human ↔ Financial capital trade-off? |
| IFRS 8 | Segment reporting | Which segments convert capital to economic value most effectively? |
| IFRS 18 | Performance presentation | Which performance architecture best supports decision-useful operating and financing interpretation? |
