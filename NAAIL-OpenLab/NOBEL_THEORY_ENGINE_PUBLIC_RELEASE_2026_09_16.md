## Architecture decision

This release preserves exactly two permanent cores:

1. **Stable Knowledge Core™**
2. **Replaceable Technology Core™**

The **NAAIL Nobel Theory-to-Evidence & AI Experiment Engine™** is a cross-cutting governed supporting capability. It is not a third core and is not CCCMP-specific.

## Public scientific path

**Theory → Construct → Variable → Rights-cleared Data → AI Experiment → Digital Twin → Causal Test → Replication → FT50/AJG Benchmark → Evidence Passport™ → Human Gate™.**

## Public scope

The Engine serves Accounting, Auditing, Finance, Economics, Management, Governance, Sustainability, Behavioral Science, Education and Research.

Public theory families cover behavioral judgment, experimental economics, behavioral economics, asset pricing, portfolio/corporate finance, risk/options, information asymmetry, contracts/incentives, transaction costs/governance, mechanism design, auctions, causal inference, institutions/development, and innovation/growth/AI productivity.

Public source families and technology references remain subject to current license, provenance, quality and execution verification. GitHub repositories are technology/replication resources, not automatically authoritative data sources.

Behavioral/text measures are empirical research constructs and are not psychological diagnoses.

**Theory → Literature Evidence → Causal DAG → Hypotheses → Power Analysis → Pre-registration → Data → Variable DNA™ → Randomization/Identification → AI Treatment → Behavioral Measures → Main Test → Robustness → Falsification → Replication/OOS → FT50/AJG Benchmark → Evidence Passport™ → Human Gate™.**
