## Open-source reference stack

Priority references include EFRAG's Digital Template to XBRL Converter, OS-Climate physrisk, Klimatbyrån garbo, Open SDG, Taxonomy4Good, and Altiorem Data. Additional climate, carbon, energy, ontology and sustainable-finance repositories are governed through the machine-readable registry and must pass license/data-rights review before runtime promotion.

## Standards and rights boundary

Authoritative ESRS/EU, IFRS Sustainability/SASB, GRI and UN materials remain external canonical sources. NAAIL may store rights-cleared metadata, mappings, version identifiers, provenance and research annotations, but must not assume that public access grants permission to republish protected standards text.

The Technology Core and external repositories may read governed sustainability knowledge through a read-only contract but may not silently rewrite the frozen Knowledge & RAG Core.

## Shared governance

This family inherits the common NAAIL sequence:

`literature validation → source/rights review → current regulatory-status check → evidence provenance → hypothesis competition → DAG governance → empirical conversion → robustness → replication/OOS → adversarial review → falsification → Evidence Passport™ → Human Gate™`

No ESG score, SDG mapping, emission estimate, climate scenario or agent conclusion is treated as professional truth merely because a model or repository produced it.
