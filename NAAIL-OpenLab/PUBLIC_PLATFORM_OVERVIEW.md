## 1. Permanent architecture

NAAIL has exactly two permanent cores:

1. **Stable Knowledge Core™** — governed scientific/professional meaning, theory, standards, evidence semantics, causal structures, construct definitions and human/professional judgment.
2. **Replaceable Technology Core™** — models, agents, RAG/GraphRAG/KAG implementations, databases, simulation engines, APIs, connectors, programming environments, MCP/A2A, observability and evaluators.

**No third permanent core is permitted.** New capabilities extend NAAIL through modular layers, specialist agents/programmes or replaceable technology.

## 4. Stable meaning vs replaceable implementation

NAAIL separates scientific meaning from implementation choice.

Examples:

- innovation theory, Kahneman-style behavioral theory, contract theory and causal inference → Stable Knowledge Core™;
- SEC/FRED/patent/startup evidence → Data & Evidence Mesh™;
- Mesa/oTree/HARK/FinRL/DoWhy → Replaceable Technology Core™;
- governed retrieval semantics/ontology/source authority → Stable Knowledge governance;
- vector DBs, graph engines, embeddings, RAG/GraphRAG/KAG frameworks → Replaceable Technology Core™;
- Innovation & Entrepreneurship and Behavioral Science → cross-cutting layers;
- CCCMP™ → specialist programme;
- Business School Digital Twin → cross-cutting simulation layer.

## 5. Architecture principle

**Stable Theory / Knowledge → Evidence / Data → Replaceable Technology → Agents / Simulations → Decision → Verification → Evidence Passport™ → Human Approval Gate™**

## 7. Scientific research standard

Publication-grade studies should, where applicable, document:

**Theory → Literature Evidence → Causal DAG → Hypotheses → Power Analysis → Pre-registration → Data → Variable DNA™ → Randomization/Identification → AI Treatment → Behavioral Measures → Main Test → Robustness → Falsification → Replication/OOS → FT50/AJG Benchmark → Evidence Passport™ → Human Gate™**

Current FT50/AJG status must be verified when used rather than hard-coded from historical lists.
