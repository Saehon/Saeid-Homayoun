# Big4 Official Resources → Research Integration Map

Purpose: connect verified public Big Four resources to the repository's accounting, auditing and assurance research stack without importing proprietary material.

## Architecture

Big4 official/public references
→ Evidence & license check
→ Research benchmark layer
→ Audit / IFRS / ICFR / ESG / AI-Assurance modules
→ Independent validation / falsification
→ Human academic/professional review

## Connections to Saehon repositories

- `AAA`: audit-agent and professional assurance research; use Big4 material only as a public benchmark/evidence source.
- `IFRS-AI-Inspector`: compare outputs against public Big4 IFRS technical material where legally accessible; authoritative standards remain the governing source.
- `IFRS-PCAOB-AI`: benchmark public audit/inspection technology concepts while keeping PCAOB standards and primary regulatory evidence separate.
- `AuditData-API`: potential metadata/reference layer for public audit resources; do not ingest copyrighted/proprietary full text without permission.
- `financial-services`: public technology/financial-services benchmark layer.
- `NAAIL-OpenLab` (within the main repository, where applicable): education/research integration layer with evidence provenance and human approval.

## Scientific-use rules

1. Primary standards/regulatory sources outrank Big4 commentary.
2. Every external artifact must retain source provenance.
3. “Official” and “third-party/Big4-related” sources must remain separate.
4. Open-source repositories require a license check before code reuse.
5. Public web availability does not imply permission to redistribute full text.
6. Firm guidance can be used for comparison and research but is not a substitute for IFRS, PCAOB, SEC, IAASB or other authoritative requirements.
7. AI-generated comparisons should pass an independent review/falsification step before research conclusions.
8. Final academic/professional judgment remains human.
