# Security Policy

## Supported scope

This repository documents ECONOVA-S™ research architecture and selected implementation artifacts. Security issues relating to published code, configuration, dependency use, or disclosure of sensitive implementation information should be reported privately rather than posted in a public issue.

## Reporting a vulnerability

Do not publicly disclose exploit details, credentials, tokens, private endpoints, confidential data, or vulnerabilities before the repository owner has had a reasonable opportunity to assess them.

Use a private contact channel associated with the repository owner for security reports. Include:

- affected file/component;
- reproducible steps;
- expected and observed behavior;
- potential impact;
- suggested mitigation, if available.

## Sensitive information

Never commit API keys, passwords, access tokens, private datasets, licensed material, customer information, invention disclosures, patent drafts, or confidential commercial information to this public repository.

## AI and agent security

Reports concerning prompt injection, unauthorized tool execution, data exfiltration, agent-to-agent privilege escalation, model-routing failures, provenance tampering, chronology bypass, or Evidence Passport integrity are treated as security-relevant issues.

## Disclosure

Public disclosure should occur only after remediation or coordinated agreement with the repository owner.
