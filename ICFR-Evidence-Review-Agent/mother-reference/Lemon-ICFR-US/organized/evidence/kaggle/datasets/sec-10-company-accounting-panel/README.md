# SEC 10-Company Accounting Panel

A reproducible annual accounting panel bootstrapped from U.S. SEC-filed 10-K comparative statements, with CompanyFacts refresh code maintained in the canonical GitHub repository.

Companies: Microsoft, Apple, Alphabet, Amazon, NVIDIA, Meta, JPMorgan Chase, Walmart, Exxon Mobil and Tesla.

The canonical source, validation logic and provenance live in GitHub:
https://github.com/Saehon/Saeid-Homayoun/tree/main/open-data/sec-10-company-phase2

## Files

- `sec_10_company_panel.csv`
- `phase2_summary.csv`
- `sec_refresh_manifest.json`

The dataset is automatically staged from the validated GitHub source before each Kaggle version.
