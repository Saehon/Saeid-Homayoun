# Microsoft Marketplace Checklist

The intended commercial packaging is a SaaS offer / AI app or agent.

## Before listing
- [ ] Partner Center account enrolled in Microsoft Marketplace
- [ ] publisher/legal/tax/payout profiles complete
- [ ] separate DEV/test and PROD offers
- [ ] production SaaS URL
- [ ] privacy policy
- [ ] terms of use
- [ ] support URL/process
- [ ] security architecture and data-flow documentation

## Authentication
- [ ] Microsoft Entra ID SSO
- [ ] Microsoft Account support where required by offer type
- [ ] tenant-aware onboarding
- [ ] role-based access

## Transactable SaaS requirements
- [ ] landing page available continuously
- [ ] Marketplace purchase token resolution
- [ ] SaaS Fulfillment API integration
- [ ] subscription activation
- [ ] plan/quantity changes
- [ ] cancellation/deletion handling
- [ ] connection webhook
- [ ] JWT/payload validation
- [ ] entitlement update on lifecycle events

## Product certification
- [ ] end-to-end purchase test using preview audience
- [ ] upgrade/downgrade test
- [ ] cancellation test
- [ ] dependency failure test
- [ ] security and privacy review
- [ ] functional and load tests
- [ ] listing screenshots, descriptions and categories
- [ ] AI Apps and Agents category selected where applicable

## Recommended first commercial listing
Start with a narrow plan around ICFR evidence review rather than the full research platform.
