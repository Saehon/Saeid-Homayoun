# ECONOVA-S™ Version Map

ECONOVA-S uses separate version numbers for its stable scientific architecture and its executable software.

- **Canonical Architecture:** V2.5
- **Software Release:** v0.2.0
- **Proof of Concept:** POC-001
- **Status:** governed research workbench / pre-discovery
- **Release date:** 2026-09-14

## Versioning rule

Architecture versions identify changes to the scientific schema, cores, governance, and canonical research protocol. Software versions identify changes to executable implementations, interfaces, adapters, tests, and empirical tooling.

A software release does not automatically change the canonical architecture version. A model upgrade inside the Replaceable Technology Core™ does not change the Stable Economic Knowledge Core™ unless the scientific schema itself is explicitly revised.

## Current scientific constraint

`discovery_claim_allowed = false` remains the default for v0.2.0. Scientific-discovery claims require real-data provenance, construct validation, credible identification, robustness and falsification, replication or appropriate OOS evidence, economic significance, welfare interpretation, and explicit human approval.
