# NAAIL OpenLab™ — Repository Version Map

This repository contains the **NAAIL OpenLab™** umbrella platform together with specialist programmes, agents, experiments, and historical component releases. Version numbers refer to different layers and should not be treated as interchangeable.

## Canonical NAAIL state

- **Architecture:** V2026.3 Multi-Agent Digital Twin
- **Constitution:** frozen two-core architecture
- **Permanent cores:** Stable Knowledge Core™ + Replaceable Technology Core™
- **Validated public executable checkpoint:** v0.2.3
- **Audit Workspace:** V0.4
- **Validated prototype:** Prototype 003
- **Status:** non-commercial research and education platform

## Research-development boundary

Architecture descriptions, new agents, research prototypes, integrations, or future-target capabilities do not automatically create a new validated executable release. Later capabilities remain at their documented maturity level until their validation gates are completed.

## Specialist component versions

Individual specialist programmes may retain their own historical software or architecture versions. For example, ECONOVA-S™ has separate component version history. Those component versions do not replace the canonical NAAIL OpenLab platform identity or the validated NAAIL checkpoint above.

## Versioning rule

Architecture versions identify changes to platform structure, governance, scientific schemas, and capability placement. Executable release versions identify validated software checkpoints. Prototype identifiers track bounded experiments or demonstrations.

A model, provider, dependency, or implementation upgrade inside the Replaceable Technology Core™ does not by itself change the Stable Knowledge Core™, the validated executable checkpoint, or the scientific status of a claim.

## Scientific constraint

Passing software tests or GitHub Actions demonstrates technical execution only. Publication-grade or professional claims still require appropriate provenance, construct validity, identification, robustness, falsification, replication or out-of-sample evidence where applicable, and explicit human review.
