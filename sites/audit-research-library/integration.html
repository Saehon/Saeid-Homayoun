Authorization and privacy

Three levels of publishing

1

Navigation (prepared)

Public repository paths, publication profiles, static project descriptions and research status labels. No licensed dataset or model is copied.

2

Free Static Space (pending)

Website-only GitHub-to-Hugging-Face publishing via a personally configured, manual Trusted Publisher. The connector remains read-only.

3

Models/data (future; gated)

Independent rights check, exact file release list, model card, synthetic leakage assessment, human approval and separate HF repository OIDC publisher.
