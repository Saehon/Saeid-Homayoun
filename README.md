## Fixed architecture: exactly two permanent cores

NAAIL preserves exactly two permanent cores:

1. **Knowledge Core™** — governed accounting, audit, finance, economics, sustainability, behavioral theory, standards, evidence semantics, ontologies, causal structures, research knowledge, and professional judgment.
2. **Technology Core™** — replaceable LLMs, agent runtimes, RAG/GraphRAG/KAG, simulation tools, analytics, connectors, databases, evaluators, Python/R/Stata, and execution infrastructure.

No supporting programme, agent, Digital Twin, data layer, simulation layer, or evaluation mechanism becomes a third core.
