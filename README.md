## Fixed architecture: exactly two permanent cores

NAAIL preserves exactly two permanent cores:

1. **Stable Knowledge Core™** — governed theory, standards, accounting/audit/finance/economics/sustainability knowledge, research evidence, constructs, ontologies, causal structures, evidence semantics, and professional judgment.
2. **Replaceable Technology Core™** — LLMs, agent runtimes, RAG/GraphRAG/KAG, simulation and experimental tooling, causal/ML tooling, databases, connectors, evaluators, Python/R/Stata, and execution infrastructure.

**No third core is permitted.** Every agent, engine, programme, Digital Twin, data layer, simulation layer and evaluation system is a supporting capability under these two cores.

**Theory → Construct → Variable → Rights-cleared Data → AI Experiment → Digital Twin → Causal Test → Replication → FT50/AJG Benchmark → Evidence Passport™ → Human Gate™**

## Scientific research standard

Publication-grade NAAIL studies should, where applicable, document:

**Theory → Literature Evidence → Causal DAG → Hypotheses → Power Analysis → Pre-registration → Data → Variable DNA™ → Randomization/Identification → AI Treatment → Behavioral Measures → Main Test → Robustness → Falsification → Replication/OOS → FT50/AJG Benchmark → Evidence Passport™ → Human Gate™**

When journal status is used, NAAIL verifies the current Financial Times FT50 list and current Chartered ABS Academic Journal Guide rather than hard-coding historical rankings.

Statistical significance, agent consensus, predictive accuracy or model confidence alone is not treated as scientific truth.
