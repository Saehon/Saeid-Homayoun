# Independent FT50 / AJG replication gate

**A candidate is not a successful replication until every applicable gate is checked by a human reviewer.**

| Gate | Minimum evidence |
| --- | --- |
| Original study | DOI, journal page, journal-tier/source verification |
| Code availability | Original author/journal link, version/commit, license and permitted reuse |
| Data provenance | Exact source, rights, coverage, whether any provided values are pseudo-data |
| Frozen execution | Environment file, dependency versions, run commands, code hash |
| Numerical comparison | Target table/figure, reproduced values, tolerances, discrepancy log |
| Design transfer | Explain any changes to sample, timing, estimator or model; no claim of exact replication if altered |
| Independent verification | Second reviewer confirmation, signed decision, timestamp |
| Human gate | REVIEW_REQUIRED until explicit approval; no automatic publication claim |

Prioritize one disclosure/text package, one asset-pricing package and one ICFR/accounting/audit package. Use verified publisher and author archives. Simulation and pseudo-data may validate a pipeline only. Record unavailable licensed inputs explicitly rather than treating the exercise as full replication.

Downstream extensions (NEVM, evidence-topology graph, independent assurance verification, digital twin) need pre-specified holdouts, placebo/negative controls, cluster-appropriate inference, robustness and null-effect reporting. Do not equate a software smoke test with an empirical JF/JFE/AJPT result.
