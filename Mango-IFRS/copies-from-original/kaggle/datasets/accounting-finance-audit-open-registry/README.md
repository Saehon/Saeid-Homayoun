# Accounting, Finance & Audit Open Data and Program Registry

Public cross-platform registry for free/open or research-accessible accounting, auditing, assurance, finance, fraud/AML, SEC/XBRL, ESG, Microsoft/Copilot and IBM/watsonx resources.

## Included files

- `program_catalog.csv`
- `data_catalog.csv`
- `combined_catalog.csv`
- `repos.yml`
- `data_sources.yml`
- `REGISTRY_MANIFEST.json`
- `SHA256SUMS.json`

This dataset mirrors **metadata and links only**. It does not redistribute third-party source code or large upstream datasets.
