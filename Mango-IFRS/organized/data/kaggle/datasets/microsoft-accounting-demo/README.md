# Microsoft Accounting Demo — SEC 10-K

This Kaggle dataset is a distribution mirror of the canonical dataset in:

`Saehon/Saeid-Homayoun/open-data/microsoft-demo-001/`

It contains Microsoft FY2024–FY2026 revenue, gross profit, operating income and net income, with provenance to the FY2026 Form 10-K.

**Source of truth:** GitHub canonical dataset.  
**Primary evidence source:** U.S. SEC EDGAR.  
**Purpose:** education, reproducible research and open accounting-data demonstrations.

The GitHub Actions Kaggle workflow stages the canonical CSV and provenance file immediately before publication, reducing manual-copy drift.
