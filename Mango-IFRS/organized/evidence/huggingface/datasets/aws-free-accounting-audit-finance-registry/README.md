# AWS Free Data Registry for Accounting, Audit, Finance & ESG

A provenance-first registry curated for NAAIL OpenLab™ / FRANKENSTEIN™.

It identifies free/open AWS-hosted or AWS-delivered sources useful for accounting, auditing, assurance, finance, macroeconomic analysis, ESG, carbon accounting, Scope 3 and climate-risk research.

## Important

This dataset mirrors metadata and links only. It does not redistribute third-party AWS Marketplace datasets whose vendor terms may restrict redistribution.
