# Build Roadmap

## Phase 1 — IFRS 15 vertical slice
- Evidence ingestion contract
- IFRS 15 metadata/rules
- deterministic calculations
- multiple treatment hypotheses
- adversarial challenge
- evidence lineage
- human approval

## Phase 2 — Evaluation
- 20–50 synthetic and expert-labelled cases
- accuracy and evidence-coverage metrics
- contradiction detection
- cost and latency benchmarks
- failure library

## Phase 3 — Engine Factory
Reusable templates for IAS 36, IAS 37, IFRS 9, IFRS 16, IFRS 3 and IFRS 18.

## Phase 4 — Enterprise integration
Adapters for ERP, contracts, close data and audit evidence. Customer data stays outside the public repository.

## Phase 5 — Assurance and value
Assertions, controls, testing, falsification, digital-twin scenarios and six-capital value consequences.

## Phase 6 — Learning loop
Human overrides, audit outcomes, realized values and evaluator performance without final-test leakage.
