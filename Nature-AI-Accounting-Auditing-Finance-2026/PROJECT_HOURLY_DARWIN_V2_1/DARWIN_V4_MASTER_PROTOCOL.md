# DARWIN V4 — Universal Project Protocol

Effective 2026-10-11. Canonical full protocol: https://docs.google.com/document/d/195VMHhp_Ua8H8dcRzejkxsOdsbofCImr6_mn1U6Cl3Q/edit

## Data sourcing priority (V3)
1. Existing verified real data in Google Drive. 2. Free official academic sources: SEC, Ken French, Damodaran, SRAF, PCAOB, scholarly data and replication repositories (verify licensing and actual free access). 3. GitHub. 4. Kaggle. 5. Hugging Face. Select by validity, provenance, point-in-time alignment, firm/year coverage, rights, and reproducibility. Do not fabricate observations or statistical outputs.

## Execution and reporting (V4)
Each hourly run: read previous verified state; perform one dependency-admissible scientific step; compare validated methods; update the five project artifacts; save versioned RUN_ID report in canonical Google Drive project folder and GitHub project path; verify both readbacks. Mandatory status report fields: project, local run timestamp, phase, executed task, evidence/source IDs, actual sample counts if verified, actual test output if executed, result status, difference from previous run, blocker, next action, Drive folder/artifact URLs, GitHub path and commit URL. Update PROJECT_MASTER_INDEX. Preserve history and proprietary-data restrictions. Two failed attempts quarantine blocker. Human approval before submission or merge.

ChatGPT limitation: A scheduled task may report in its own task conversation, but does not guarantee writing to an unrelated existing ChatGPT Project chat. Do not claim project-page publication unless verified; users can access latest snapshots through project Drive/GitHub links.
