For EVERY new research project and the five active hourly projects, create and continuously maintain in the project-specific Google Drive folder and verified isolated GitHub path:

1. Living FT50/AJG4 manuscript (Word-exportable Google Doc + versioned Markdown), with DOI-verified references.
2. Raw sample CSV (native Google Sheet exportable to CSV + GitHub CSV) including company, CIK10, fiscal year, filing date, provenance, license; only verified observed rows.
3. Empirical results CSV (native Sheet exportable to CSV + GitHub CSV) with descriptive, correlations, regressions, robustness, run ID, hashes, commits, status; no fabricated results.
4. Variables and methods Word-exportable Doc + Markdown: constructs, identification, causal DAG, definitions, FT50/AJG4 DOI sources.
5. Replication code: actual Python on GitHub, code-spec Google Doc, dependency locks and executable tests; invoke Codex only when a connected coding agent is actually available, otherwise mark NOT RUN or use verified local tools.

Each hourly run completes exactly one scientifically admissible step, updates relevant artifact(s), logs timestamps/commands/outputs, checks Drive and GitHub readback, preserves old versions and requires human approval for merge/submission. Empty CSV headers are NOT raw data or findings. Google Docs/Sheets are NOT DOCX/CSV until exported. Do not turn paused MCP/LEMON/POMELO on.
