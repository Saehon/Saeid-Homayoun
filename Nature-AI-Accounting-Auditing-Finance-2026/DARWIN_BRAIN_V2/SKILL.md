# DARWIN BRAIN V2
Use this file as Claude-compatible SKILL.md and as instructions for GPT projects. File publication does NOT automatically install or activate a skill.

## Core workflow
1. SYSTEMS THINKING: map stakeholders (CFO, auditor, committee, regulator, investor, AI provider), boundaries, incentives, reinforcing/balancing loops, delays, unintended consequences, causal DAGs and leverage points.
2. 100 CEO LENSES: create 100 SYNTHETIC perspectives, not real CEO testimony, as 10 dimensions (capital, customers, talent, technology, operations, risk, governance, innovation, sustainability, regulation) × 10 archetypes (incumbent, challenger, platform, industrial, services, finance, public interest, turnaround, frontier, global). For each: assumption, intervention, downside, falsifiable KPI. Retain disagreement.
3. AGENTS: DISCOVER verifies citations, DOIs, datasets and licenses; THEORIST builds competing hypotheses; DESIGNER sets identification/power; BUILDER executes; ADVERSARY tests bias/leakage; REPLICATOR independently reruns; EDITOR checks journal fit; HUMAN GATE approves.
4. EVOLUTIONARY SEARCH: generate >=3 competing designs; score novelty, identification, free-data feasibility, reproducibility, ethics, journal fit from 0–5; retain Pareto-efficient candidates; falsify rather than tune for significance.
5. NATURE TRANSFER: Paper2Agent-style paper-to-executable mapping, Co-Scientist-style debate, AI-Scientist-style experimental loops. For every paper record verified title, DOI, method, code, data, rights, applicability and verification status; no invented replication.
6. EIGHT GATES: provenance; rights/license; COSO/ICFR or IFRS/GAAP grounding; evidence sufficiency; independent review; falsification; reproducibility; human approval. Human gate NEVER auto-passes.
7. PROJECT ROUTES: ICFR–SEFD–SEC–TimesFM (out-of-time prediction); Risk–CAM (ex ante account risk × CAM, future outcomes); PCAOB (inspection evidence lineage); AI CapEx (text, cash flows, pricing); ESG (claim verification); FT50 Paper2Agent (reproduce then extend); NAAIL/LEMON/POMELO (reuse repository safeguards).
8. HOURLY PHASE: read canonical Drive index and GitHub commit; perform one smallest admissible step; log output/checksums; independent QA; save versioned outputs to Drive and code via GitHub PR; update index; report PASS/PARTIAL/BLOCKED/NOT RUN. Scheduling requires separate automation. After two failed attempts quarantine blocker and move only to independent work.
9. FT50/TAR GATE: require real empirical observations, valid identification, executed statistics and uncertainty, robustness, independently verified references and human approval. Synthetic demonstration is not real evidence.

## Required outputs
System map, 3 candidate designs, hypotheses, verified literature matrix, preregistration, data dictionary, replication scripts, robustness and falsification logs, manuscript, PROJECT_MASTER_INDEX and human disposition.
