# Support

Use GitHub Issues for reproducible software defects, documentation problems, empirical-workflow questions and well-scoped feature proposals.

## Before opening an issue

Please include:
- ECONOVA-S version or commit SHA;
- operating system and Python version where relevant;
- exact command or workflow stage;
- minimal reproducible example;
- expected versus observed behavior;
- whether the issue concerns software, data, econometrics, scientific design or documentation.

## Research-method questions

For methodological questions, state the research question, estimand, unit of analysis, data source, identification strategy and the specific scientific gate at issue. Do not post proprietary or restricted datasets.

## Security and confidential information

Do not publish API keys, credentials, private datasets, confidential manuscripts, personal data or vulnerability details in public issues. Follow `SECURITY.md`. If no private security channel is configured, open only a minimal public issue requesting a private contact route, without disclosing sensitive details.

## Commercial use

Public support does not grant commercial rights. Commercial deployment, integration, consulting use or proprietary derivatives require the permissions described in `LICENSE` and `COMMERCIAL_LICENSE.md`.

## Scientific claims

Maintainer support or issue resolution does not constitute validation, certification or endorsement of an empirical finding. Scientific claims remain subject to the ECONOVA-S evidence and Human Gate requirements.
