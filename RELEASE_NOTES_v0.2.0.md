# ECONOVA-S™ v0.2.0 — Real Data + Evidence RAG

**Release status:** release candidate documentation prepared. A formal GitHub Release has not yet been published.

## Highlights

ECONOVA-S v0.2 moves the project from architecture feasibility to a governed research workbench combining GPT-5.6 Sol, controlled evidence retrieval, real-data ingestion, econometrics, temporal OOS validation, scientific red-team review, Evidence Passport™ generation and a Human Gate.

## Added

- GPT-5.6 Sol as a replaceable model backend.
- Relevance-gated evidence metadata registry.
- Optional public web search and user-owned/licensed File Search integration.
- Official Fama–French 5-factor data adapter.
- Verified CSV ingestion for firm-year, market and Climate TRACE exports.
- Six-table empirical workflow.
- Entity/time fixed effects and clustered/HC3 inference.
- Temporal holdout/OOS check.
- Stata `.do` export.
- Independent Scientific Red-Team Agent™.
- Evidence Passport™ with data and empirical-gate manifests.
- Human Gate.
- GitHub Actions test workflow.

## Scientific safeguards

- Empirical outputs are associational by default.
- Fixed effects and clustered errors do not imply causal identification.
- Literature metadata does not substitute for reading and validating primary research.
- The model cannot approve its own scientific discovery.
- `discovery_claim_allowed = false` remains hard-coded in v0.2.

## Verification

Local validation covered evidence retrieval, econometrics/OOS, Stata export and discovery-gate behavior.
