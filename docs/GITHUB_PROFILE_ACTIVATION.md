# Activate the Saehon GitHub Profile README

The finished profile README is stored in:

`docs/GITHUB_PROFILE_README.md`

GitHub displays a profile README only when a **public repository with the exact same name as the account** exists.

For this account, the repository must be:

`Saehon/Saehon`

## One-time activation

1. Open: https://github.com/new
2. Set **Repository name** to `Saehon`.
3. Choose **Public**.
4. Check **Add a README file**.
5. Create the repository.
6. Replace that new repository's `README.md` with the exact contents of `docs/GITHUB_PROFILE_README.md` from the flagship repository.

After the repository exists, the GitHub profile page at https://github.com/Saehon will automatically render its README.

## Canonical source

Until the profile repository exists, this flagship copy is the controlled source for the public profile text. Future profile revisions should be made through a focused issue and pull request so changes remain reviewable and reproducible.
