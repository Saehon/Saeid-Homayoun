# Manuscripts and submission-ready packages

Journal targeting is a hypothesis about fit, never a guarantee. Compare contribution with accurately verified FT50/AJG literature and the target journal's current author guidance. Differentiate accounting research audiences: TAR/JAR/JAE/RAST/CAR, finance/management outlets and specialist audit/forensic venues.

Standard package as requested:
- Main manuscript: title/abstract, theoretical contribution, hypotheses, data and design, identification, results, mechanisms, robustness, limitations, conclusion.
- Tables: sample construction, descriptive statistics, correlations, baseline models, tests of key assumptions, robustness, predictive validation where applicable.
- Online appendix: variable dictionary, sample filters, additional tables, alternative measures, documented data sources and verified citations.
- Replication materials: environment lockfile, deterministic scripts, provenance manifest, data licenses/access note, run instructions, output checks and tests. Restricted raw data should not be redistributed.
- Editorial materials when required: cover letter, response to reviewers, blinded manuscript, separate title page, declarations.

Apply a quality gate to check: verified sample sizes, concordant table/text numbers, source traceability, correct chronological ordering, licensed data, executable replication code, and non-fabricated references. Include a results ledger distinguishing EXECUTED from PLANNED analyses. Never optimize toward significant results.
