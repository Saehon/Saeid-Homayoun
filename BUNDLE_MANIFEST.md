# Saeid research companion skills

Release: `2026-10-08-r1`

This bundle contains the four specialist skills installed alongside the master `saeid-research-systems` skill. Each directory includes its `SKILL.md`, ChatGPT interface metadata, generated icon, and one focused reference file.

| Skill | Installed registry ID | Scope |
| --- | --- | --- |
| `ft50-abs4-replication` | `skill-6ac74b4e01d08191827538d5d443ae9e` | FT50/AJG4/ABS4 positioning, replication gates, reviewer and submission packages |

The bundle preserves source files; it does not delete or overwrite the original research archive. Public-source names are treated as sources to verify at run time, with version, license, timing, and provenance recorded before use.
