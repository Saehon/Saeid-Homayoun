# Big Four — Official & Verified Public Resources

This directory is a curated reference layer for public resources that can be verified as belonging to, or explicitly associated with, Big Four firms.

## Verification policy

- Prefer first-party corporate/organizational accounts and official firm websites.
- Do not label third-party repositories as official.
- Do not copy proprietary Big Four material into this repository.
- Open-source code may only be reused subject to its repository license.
- This page is for non-commercial education and research.
