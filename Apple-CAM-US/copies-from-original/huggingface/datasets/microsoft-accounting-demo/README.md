# Microsoft Accounting Demo — SEC 10-K

A compact accounting dataset for Microsoft Corporation (MSFT), covering FY2024–FY2026.

## Fields

- `fiscal_year`
- `revenue_musd`
- `gross_profit_musd`
- `operating_income_musd`
- `net_income_musd`

Amounts are USD millions.

## Provenance

Primary source: U.S. SEC, Microsoft Corporation FY2026 Form 10-K, accession **0001193125-26-323660**.

Canonical source and validation code:

`Saehon/Saeid-Homayoun/open-data/microsoft-demo-001/`

GitHub is the source of truth; this Hugging Face dataset is a distribution mirror for open research, agents and machine-learning workflows.
