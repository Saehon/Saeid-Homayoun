# CAM/KAM AuditBERT Public Demo

This is a **public-safe synthetic demonstration dataset** accompanying research on AI-assisted analysis of Critical Audit Matters (CAMs) and Key Audit Matters (KAMs).

## Contents
The public dataset contains synthetic examples only and is intended to test schema, preprocessing and model pipelines.

## Recommended fields
`title`, `description`, `response`, `conclusion`, `topic`, `matter_type`, `jurisdiction`, and provenance fields.

## Important limitation
The underlying research project uses additional private/licensed data. Those records are not redistributed here.

## Research use
The demo can support reproducible preprocessing and educational examples. It does not represent an audit conclusion or regulator-validated model.
