# Audit AI

Purpose: audit evidence, risk, assurance and audit-analytics research.

IBM-enabled components:
- Docling for audit-report, workpaper-like document and table ingestion
- Granite for extraction, classification, structured analysis and agent tool use
- BeeAI Framework for Auditor → Reviewer → Falsification orchestration
- Optional IBM OpenPages Internal Audit Management adapter for enterprise GRC workflows

Human professional judgment remains the final gate.
