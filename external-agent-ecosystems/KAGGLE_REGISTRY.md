# Kaggle Accounting, Audit, Finance & ESG Registry

Curated Kaggle resources for research, benchmarking and reproducible agent evaluation. Upstream resources remain with their original Kaggle owners; this registry does not redistribute them.

## Reproducibility and governance

Before using an upstream Kaggle asset in research, record its owner, license/competition rules, version, retrieval date, provenance, permitted use and validation status. Do not copy competition-restricted data into this repository.
