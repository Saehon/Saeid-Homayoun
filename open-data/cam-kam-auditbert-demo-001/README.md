# CAM/KAM AuditBERT Demo 001

Canonical open-data demonstration package for the CAM/KAM AuditBERT research project.

This folder contains **synthetic data only**. It is designed to validate the research pipeline without redistributing unpublished manuscript content or licensed Audit Analytics observations.

## Files
- `synthetic_cam_kam_sample.csv` — three synthetic CAM/KAM records.
- `validate.py` — schema and row-count validation.
- `provenance.json` — provenance and redistribution statement.

## Linked research models
- Topic classifier: https://huggingface.co/MaRyAm1295/finBERT-KAM
- Response generator: https://huggingface.co/MaRyAm1295/Llama-3.1-8B-KAM

## Public/private boundary
Use this synthetic package for public reproducibility. Keep licensed/raw research data in private storage unless redistribution rights are confirmed.
