# Accounting AI

Purpose: AI-assisted financial-accounting research and evidence analysis.

IBM-enabled default pipeline:
`Docling → Granite Embeddings → Granite LLM → Reviewer → Human Gate`

Primary uses:
- financial statement and note extraction
- XBRL/document ingestion
- accounting-policy classification
- anomaly and inconsistency screening
- evidence-grounded RAG
- structured research coding

Paid IBM services are optional adapters, not requirements.
