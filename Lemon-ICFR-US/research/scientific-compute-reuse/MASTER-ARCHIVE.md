## Co-Scientist and discovery
Generate competing hypotheses for residual structure. Pattern != Discovery. Pattern → Hypothesis → Mechanism → Falsification → Replication → Transportability → Candidate Knowledge.

## Falsification before evolution
Generate → Falsify → Evaluate → Evolve. Test temporal, industry, size, regulatory, outcome-definition, ontology, compiler, leave-one-out, negative-control, calibration and common-bias challenges.

## Knowledge promotion
L0 Pattern → L1 Hypothesis → L2 Falsification Survivor → L3 Replicated → L4 Transportable → L5 Executable Scientific Knowledge. Only L5 enters the next bank after human approval.

## Anti-leakage
Lock M1 before opening existing ML results. Final test data cannot select papers, variables, weights, thresholds, hypotheses, mutations or hyperparameters. Never guess coefficients/intercepts/FE/definitions. Failed models remain visible.

## Evaluation
Primary: PR-AUC. Secondary: ROC-AUC, Brier, Recall@20%, Precision, FPR, calibration, coverage. Also measure training/inference time, CPU/GPU, memory, token/API cost, human validation time and monetary cost.

## Learning loop
If validated discovery D_t is admitted: `S_(t+1)=S_t+D_t`, `U_(t+1)=U_t-D_t`. Monotone knowledge growth is tested, not assumed.

## Permanent rules
ICFR only; published science first; replication before trust; falsification before claim; no ML leakage into M1; no fabricated results; M1–M4 comparison only after M1 lock; performance and compute measured together; human scientific judgment is final.
