# LEMON-SCI × DARWIN × Codex — Hourly Autonomous Scientific Engineering Protocol

## Mission
Continue LEMON-SCI / Lemon-ICFR-US as a resilient scientific-engineering project. Optimize for verified scientific progress, reproducibility, falsifiability, provenance integrity, leakage control and eventual completion—not merely green CI.

## Hourly cadence
Execute one work cycle every hour when invoked/scheduled. Each cycle should contain at least 15 minutes of effective scientific/engineering work when the environment permits: approximately 0–5 minutes state/evidence, 5–10 minutes implementation/provenance/tests, and 10–15+ minutes falsification, deterministic checks and independent review. Do not wait/sleep to fill time. If the environment ends early, record PARTIAL_RUN; never fabricate elapsed time.

## DARWIN for every substantive gate
D Define scientific/engineering problem and acceptance gate.
A Alternatives: generate credible competing specifications/repairs.
R Retrieve & Replicate primary evidence, replication materials, Drive provenance, repository history and tests.
W Whole-system effects across model bank, compiler, applicability, temporal design, M1–M4, schemas, CI and provenance.
I Invalidate/Falsify via negative, boundary, mutation, leakage and deterministic tests plus independent challenge.
N Next Evolution = PASS / REVISE / BLOCKED / DEPENDENCY_CRITICAL. Never force PASS.

## Blockers
LOCAL: preserve evidence → deterministic repair → adversarial challenge → retest → continue independent safe work.
DEPENDENCY_CRITICAL: do not bypass the scientific gate; continue independent safe work.
Do not repeatedly investigate the same blocker without new evidence.

## Scientific firewall
Before M1 Lock, never allow M2/M3/M4 performance, holdout outcomes, Kaggle/Hugging Face leaderboards, prior accuracy or desired significance to influence M1 literature, coefficients, transformations, thresholds, weights or definitions.

## Engineering pass is not scientific pass
Maintain ENGINEERING_PASS separately from SCIENTIFIC_PASS. Green CI is engineering evidence only.
ACK2007 Freeze requires simultaneously: PRIMARY EVIDENCE PASS + REPOSITORY IMPLEMENTATION PASS + ADVERSARIAL/FALSIFICATION PASS. Otherwise SCIENTIFIC_HOLD / NOT_M1_LOCKED.

## Continuous execution
Do not spend a run merely reporting status. If a gate passes, immediately begin the next scientifically admissible gate in the same run. If a dependency-critical gate is blocked, advance independent infrastructure, provenance, tests, determinism, schema hardening or falsification preparation.
