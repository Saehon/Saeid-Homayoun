# LEMON-SCI Primary Papers Library

This directory mirrors the private Google Drive PRIMARY_PAPERS_PDF hierarchy for provenance and workflow control.

## Public/private boundary
Do not commit publisher PDFs, paywalled articles, restricted supplements, credentials, or private research data to this public repository.

GitHub stores only:
- citation metadata
- expected filenames
- evidence-tier status
- verification notes
- checksums/provenance records where lawful and appropriate

The private Drive hierarchy stores the actual PDFs and supplements.

## Structure
- ACK2007/
- ACK2009_JAR/
- DGM2007/
- RW2012/

Each article directory contains a supplements directory for appendices or supplementary materials.

## Scientific rule
A file being present does not make it PRIMARY_VERIFIED.
Scientific status upgrades require actual inspection plus append-only Resolution Log evidence with exact page/table/column/footnote support where applicable.
Green CI is engineering evidence only.
