# Anti-Leakage Constitution

1. Build and lock M1 before opening existing ML results.
2. Final test observations cannot determine paper/model/variable selection, weights, thresholds, hypotheses, mutations, or hyperparameters.
3. Co-Scientist and AlphaEvolve-inspired search use training/development evidence only until final lock.
4. Failed published models remain visible.
5. Journal rank is metadata, not a truth weight.
6. Never guess coefficients, intercepts, fixed effects, or variable definitions.
7. After M1 lock compare M1/M2/M3/M4 on the same frozen evaluation design.
