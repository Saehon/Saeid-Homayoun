# FRANKENSTEIN Data Registry

This directory records **where data comes from**, not just the data itself.

## Professional data architecture

| Platform | Primary role | GitHub behavior |
|---|---|---|
| Hugging Face | public datasets and models | store source links, manifests and small reproducible samples |
| Kaggle | benchmark datasets/notebooks | store dataset IDs, provenance and download scripts; do not mirror large files |
| Google Drive | controlled research files, working papers and private project documents | store stable file references/metadata; do not expose private content publicly |
| SEC/PCAOB/ESMA/etc. | authoritative public evidence | preserve original source URLs, dates and checksums |

## Phase 1 example

`phase1_huggingface/` is generated by:

`FRANKENSTEIN/connectors/huggingface_public_example.py`

It downloads only a **small demonstration sample** from FinancialPhraseBank and writes a provenance manifest.

Upstream source:
https://huggingface.co/datasets/lmassaron/FinancialPhraseBank

The full dataset remains on Hugging Face.
