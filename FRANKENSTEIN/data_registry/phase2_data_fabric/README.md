# FRANKENSTEIN Phase 2 — Registered Data Fabric

Phase 2 establishes a live four-platform research fabric:

**Hugging Face → GitHub → Kaggle → Google Drive**

The objective is not to copy every dataset everywhere. The objective is to make provenance, licensing, versioning, and research location explicit.

## Live components

- Hugging Face source dataset:
  https://huggingface.co/datasets/lmassaron/FinancialPhraseBank
- GitHub FRANKENSTEIN:
  https://github.com/Saehon/Saeid-Homayoun/tree/main/FRANKENSTEIN
- Kaggle dataset:
  https://www.kaggle.com/datasets/sadhon/frankenstein-phase1-financialphrasebank
- Google Drive controlled registry:
  https://docs.google.com/document/d/1tf4fKoiRWX4bVdG0UMzZsTyOXg1pCZJ42qR0F4AqsKI/edit
- Google Drive FRANKENSTEIN Data Fabric folder:
  https://drive.google.com/drive/folders/1lVad4aDLmGAidGn3S34b9t9o_b4lMgEc

## Platform responsibilities

| Platform | Role |
|---|---|
| GitHub | code, manifests, checksums, tests, small reproducible examples |
| Hugging Face | public datasets and models |
| Kaggle | benchmark datasets, notebooks and public/private publication |
| Google Drive | controlled research documents, working files and review artifacts |
