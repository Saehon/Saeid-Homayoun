# OpenAI Finance & Operations Audit Profile Architecture

## Position inside FRANKENSTEIN

This profile is a replaceable implementation under the root FRANKENSTEIN programme.

| FRANKENSTEIN / NAAIL element | Profile implementation |
|---|---|
| Stable Knowledge Core | accounting, audit, ICFR, finance, governance and professional judgment |
| Evidence layer | deterministic transaction findings and source SHA-256 |
| Replaceable Technology Core | OpenAI Agents SDK, configured model, pandas/Pydantic |
| Specialist society | 11 finance/operations audit specialists |
| Adversarial review | independent Evidence Challenger |
| Programmatic verification | evidence-ID allow-list enforcement |
| Executive synthesis | Finance & Operations Audit Leader |
| Human Gate | required before consequential professional conclusions |

## Evidence contract

A deterministic finding carries a finding ID, rule ID, severity, transaction IDs, row-level evidence, rationale, domain routing and control objectives.

Agent-generated evidence identifiers are not trusted. Any unsupported finding ID is removed programmatically before promotion.

## Fail-closed behavior

If material claims have no validated finding IDs, the governance layer records missing evidence and caps confidence. The independent challenger can force revision or insufficient-evidence status. The system ends at a human review gate.
