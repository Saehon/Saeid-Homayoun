## Pilot case

Use the frozen **Revenue Recognition & Cut-off** synthetic case as the first bounded pilot.

Current preserved deterministic evidence:

- detected exceptions: `TX-002`, `TX-003`;
- proposed adjustment: `190,000` in case currency;
- precision / recall: `1.00 / 1.00` on this synthetic case only;
- runtime terminates at `PENDING_HUMAN_APPROVAL`;
- later human decision is recorded separately as `APPROVED_FOR_RESEARCH_AND_EDUCATIONAL_USE`.

These numbers are benchmark evidence for the frozen synthetic case only. They are **not** evidence of real-world audit quality, provider superiority, regulatory compliance or autonomous inspection capability.

## PCAOB-style inspection mapping

| Inspection activity | Repository capability | Governed output |
|---|---|---|
| Evidence intake | Evidence ledger + provenance | Traceable evidence IDs |
| Risk / exception identification | Deterministic tests + specialist agents | Candidate inspection findings |
| Contradictory evidence review | Challenger / falsifier | Supported vs unsupported claims |
| Documentation sufficiency | Structured evidence packets | Missing evidence / abstention |
| Cross-engagement research | AuditData / BERT / TimesFM adapter boundaries | Research signals, not conclusions |
| Regulatory judgment | Human Approval Gate™ | Qualified human decision only |

## Scientific integrity boundary

Provider-based single-agent, sequential-agent and governed multi-agent conditions remain empirical only after real provider execution on the same frozen case/evidence/evaluator. Gold labels must never be included in provider prompts. A model or provider cannot self-approve the Human Gate.

## Next empirical milestone

1. Freeze case, evidence, gold labels and evaluator.
2. Execute single-agent, sequential-agent and governed multi-agent conditions.
3. Repeat blinded runs across providers.
4. Measure grounding, precision/recall, unsupported evidence, documentation, cost and latency.
5. Run independent challenge/falsification.
6. Preserve human review as a separate evidence object.

## Presentation thesis

> A regulatory or assurance agent should be judged not by fluent answers, but by traceable evidence, falsifiability, reproducibility and preservation of human authority.
